JENNUMA BIRTHDAY WEBSITE
========================

Files
-----
index.html - complete responsive birthday website. No photos or external libraries required.

Preview locally
---------------
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome recommended).
3. Tap the music control to enable the gentle, original synthesized melody. Browsers require a tap before audio can play.

Publish free with GitHub Pages
------------------------------
1. Sign in or create a free account at https://github.com/
2. Create a new public repository, e.g. jennuma-birthday.
3. Upload index.html to the repository's root (the top-level folder). You can also upload this README.
4. Open the repository's Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes. GitHub will show the published URL in Settings -> Pages, typically:
   https://YOUR-USERNAME.github.io/jennuma-birthday/
8. Open the URL on your phone to test, then share it with Jennuma.

Important
---------
- Publishing a public GitHub Pages site means anyone with the link can view it.
- This website is a static birthday page; it does not collect data.
- The music is a gentle synthesized melody generated in the browser, not a commercial song recording.
- You can edit the wording in index.html using any text editor.
